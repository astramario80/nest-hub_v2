# Official NEST division badges

Approved Division 1 eagle-and-gear badge reused as the design reference. Full-resolution transparent files are 1254 × 1254; the website uses the 512 × 512 versions for faster loading.

Divisions: 1, 2, 3, 4, 5, 7, CTSO.

## Generation brief

Numbered badges were generated by editing the approved Division 1 reference with this instruction (substitute the division number):

> Preserve the exact orange gear outline, charcoal circle, white eagle head, composition, scale, style and transparent background of the reference. Change ONLY the large bottom numeral from "1" to the division number. Keep the small word "DIVISION" unchanged. Match the existing bold white typography, placement and size. Single badge only, no mockup.

CTSO used the same reference and preservation instruction, replacing the small word "DIVISION" with "NEST" and the large numeral with "CTSO", centered on one horizontal line inside the existing dark circle.

All new badges were generated with the image generation tool using the approved image as an edit reference. WebP encoding and website-size exports preserve transparency.
